# Security policy

RemoteX handles remote-control capabilities, authentication, and privileged Windows behavior. Please do not publish suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository and include the affected component, reproduction conditions, expected impact, and any suggested mitigation.

This repository is a curated portfolio snapshot. It contains no supported deployment, production credentials, signing secrets, or live service endpoints. Values under the reserved `.example` domain are placeholders.
